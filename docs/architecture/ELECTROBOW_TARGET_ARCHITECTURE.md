# Target architecture for the live bowed-guitar effect

**Decision.** Keep JUCE as the host adapter and `EbInstrument` as the Rust stream owner. Each input channel drives one monophonic virtual string through continuous Hz, level, articulation and timbre estimates. When a string is identifiable, a nonlinear bow supplies work to two traveling-wave delay arms. An immediate, attack-shaped guitar path carries the pick and material that cannot be tracked. A small parallel body pickup colors the synthesized harmonics. The six existing controls, neutral reconstruction and causal bypass remain available. [Source audit](../research/EXISTING_DSP_AUDIT.md), [model derivation M1–M7](BOWED_STRING_MATHEMATICS.md)

```text
host planar float -> sanitize + meter + four original guitar bands
                          |                      |
                 pre-swell samples/levels      linked Attack -> direct
                          |                                      |
                 conditioner + onset + YIN (Hz, quality)         |
                          |                                      |
                 state, dynamics, bow pressure and speed         |
                          |                                      |
                 nonlinear contact <-> two returning wave paths  |
                          |                                      |
                 bridge tap + lightly mixed body -> articulation mix
                                                    |
                               linked Out and protection -> host/bypass
```

## A1. Input and time base

Process both channels in sample order, with separate guitar-analysis lanes, contact histories, DC blockers, voice gains and clocks. Share the current host control snapshot, modulation phase, existing stereo-linked direct Attack and final output protection. Two channels with different sources can track different tones. A stereo recording of a chord is still a monophonic estimation problem **within each lane**. No mid sum can cancel an anti-phase DI. Identical samples yield identical wet audio after reset. A signed onset orientation gives an inverted copy inverted synthesized output. Stereo microphones with different waveforms may capture different features or launch a hop apart; measure that behavior explicitly. There is no attempt to extract six strings from a mixed pickup.

Support synthesis at 32–192 kHz inclusive and 65–1320 Hz. The intended range includes drop D through the two-octave high E. Retain original six-control timbral processing at other previously valid rates, and its original tail subject to the A4 host-rate guard. This keeps low-rate and unusually high-rate host behavior without allocating delays proportional to an unchecked extreme rate. Within the synthesis rate range an out-of-range or ambiguous pitch follows the shaped direct path. All time constants are seconds converted with the actual stream or analysis rate. For positive durations t seconds use max(1,floor(t·rate+.5)) samples. Positive ties round upward. Explicitly instantaneous parameters use zero. For hop length use this rule at Fₐ. No processing on zero frames.

**Conditioning.** Store the existing sanitized sample x (FS) before Attack. For analyzer x_hp=c(x_hp_prev+x−x_prev), c=exp(−2π·30/fs). For each lane maintain E_fast and E_slow in FS² by E←E+α(x_hp²−E), α=1−exp(−1/(fs τ)), τ=4 and 45 ms respectively. Define A=√max(E_fast,0), S=√max(E_slow,0). Also follow the signed pre-swell band contributions: smooth (b₂+b₃)² and (b₀+b₁)² over 25 ms. Brightness B=E_high/(E_high+E_low+1e−12) in [0,1]. The broad filters overlap; B measures a reproducible spectral balance, not a harmonic decomposition. For polarity use ten completed 1 ms peak buckets and the current partial bucket at the opening event. Update each bucket per sample, storing signed maximum by absolute magnitude and its sample index. Choose the sign of the largest absolute peak among the eleven buckets, earliest index on ties, +1 for zero. This gives a bounded scan over roughly 10 ms.

**Decimation.** D=floor(fs/8000) (4…24); Fₐ=fs/D, 8 kHz to <10 kHz for this range. Compute a causal anti-alias FIR of length 32D+1 only on every Dth input sample. For tap index j=0…32D, center M=16D, use h[j]=w[j]·2fc/fs·sinc(2fc(j−M)/fs), sinc(t)=sin(πt)/(πt), sinc(0)=1, fc=.34Fₐ. Blackman w=.42−.5cos(2πj/(32D))+.08cos(4πj/(32D)); normalize taps by their sum. Delay=M/fs=16/Fₐ, about 2 ms. Coefficients and history are preallocated. From zero-based host index 0 after prepare/reset emit decimated sample n at host (n+1)D−1. Retain phase across callbacks. Hop ends are n=(j+1)H−1 for j≥0, subject to evidence validity. FIR history before stream start is zero. Conditioning affects analysis only.

## A2. Bounded causal pitch and confidence

Use the fixed-window YIN difference of de Cheveigné and Kawahara. At analysis sample index n, W=ceil(Fₐ/65), K=ceil(Fₐ/65)+1, L=max(2,floor(Fₐ/1320)). Maintain W+K+1 decimated samples in a ring. Accumulate in f64. For τ=1…K use

```text
dτ[n] = Σ(i=0..W−1) (z[n−i] − z[n−i−τ])²
      = dτ[n−1] + (z[n]−z[n−τ])² − (z[n−W]−z[n−W−τ])²
d'0 = 1
d'τ = τ max(0,dτ) / Σ(j=1..τ) max(0,dj)
```

Zero-pad prehistory in the recurrence. Emit a decision only every H=round(.005Fₐ) decimated samples, with at least W+K valid samples and sufficient level. For a denominator ≤1e−12 FS² set d′=1. Every hop exactly recompute one lag's d from its W current pairs, cycling through 1…K, before normalization. This bounds accumulation drift without an O(WK) burst. The recurrence is a direct sliding sum of the same differences. Compare to recomputation in tests through noise, long silence and changing signals. [YIN §§II.C–F](https://www.ee.columbia.edu/~dpwe/e6820/papers/deChevK02-yin.pdf)

**Trough measurement.** In ascending integer lag order t=L…K−1 consider c[t]≤c[t−1] and c[t]<c[t+1], with c=d′. Use both neighbors at L and K−1 as well. Refine the selected integer lag with this two-sided stencil before applying the physical frequency bounds below. For a triple (a,b,c) at offsets (−1,0,+1), write C=a−2b+c, B=(c−a)/2. The unique interpolating quadratic is p(u)=b+B·u+C·u²/2. Its derivative vanishes at −B/C. For C>1e−12 use u=clip(−B/C,−.5,.5), otherwise u=0. The curvature floor is dimensionless for CMND and FS² for d. Use the value at the **clamped** offset, depth=clip(p(u),0,1), and Q=1−depth. For final Hz use a separate u from the unnormalized d triple at the selected t, with the same convexity guard. Compute f=Fₐ/(t+u). Reject nonfinite results or f outside [65·.995,1320·1.005]. Otherwise clamp to [65,1320]. A rejected selected result or missing minimum emits None with Q=0.

**Candidate-ordering reference and implementation hold.** The frozen fitted-depth comparison takes the first trough with depth<.15. If none qualifies, maintenance alone may take the smallest depth≤.26, with shortest lag breaking ties. Range validation follows selection, with no retry at a longer lag. Iterate at most K−L trough positions, retain one best candidate, use prepared arrays. No future samples, allocation, octave folding or iterative convergence. This defines an executable comparison and fixes the depth calculation. Final ordering for production remains unresolved: this first-qualifying rule fails on identifiable dominant-second inputs, and the raw-d fit exceeds the cents gate on some bright fractional periods. A1, differences, normalization and trough measurement may be implemented/tested in isolation. Do not route this selector into the voice or claim full-range pitch acceptance until the counter-fixtures in V12 pass a reviewed bounded rule. [Experiment and authorization](../implementation/status/SPECIFICATION_SIGNOFF.md)

Emit `Frame { end: u64, hz: Option<f64>, quality, fast, slow, brightness }`. End is the most recent **host** index. A pairwise difference at lag τ is centered approximately (W−1+τ)/(2Fₐ)+16/Fₐ seconds before emission. Supply this center time to offline metrics. Make rendering decisions at emission only. Starting requires both a starter-eligible candidate (depth<.15) and Q≥.85. Following an established track permits the maintenance fallback at Q≥.74. At depth=.15 the candidate can only maintain a track. Q measures normalized periodicity. Apply the level and confirmation gates below in either case. Do not fold candidates by factors of two to manufacture continuity. Require two neighboring qualifying frames within 65 cents (1200·|log₂(f₂/f₁)|) to acquire. This accepts continuous pitch; no pitch classes are used. Require three such consecutive frames for a discontinuous change exceeding 150 cents from the last accepted pitch. Small legitimate bends update every good hop. An octave-rich pluck or two commensurate notes can still look periodic. Confidence alone cannot disambiguate them.

## A3. Articulation and hold policy

All thresholds in this section are **initial control design values** to test on known DI levels. Set the quiet floor N initially to 0.00032 FS RMS (≈−70 dBFS). At every hop in Idle without an opening candidate and A<.004, update N←clip(N+(1−exp(−H/(Fₐ·1 s)))(A−N),.0001,.002); freeze it elsewhere. On threshold T_on=max(.002,6N), keep threshold T_keep=max(.001,3N). Compute these from the previous floor. Store the latest seven hop values of A and levels per gesture. A note below threshold stays direct; high-level steady hum within the playable range may be indistinguishable from a held input.

- Evaluate level/onset at each hop even before a full pitch frame exists. An opening event is the first upward T_on crossing, or a pick rise with A>T_on and A>1.65·max(S,T_keep), when armed. Rearm the rise when A<1.18·max(S,T_keep), enforce 55 ms since the previous accepted pick. This comparison uses the raw pre-swell analysis. Idle may also open on two consecutive above-threshold strong pitch frames for a soft legato entrance. Store event time and polarity, clear acquisition counters.
- A **mute** requires that 20 ms ago A was >4T_on and present A is below max(T_keep,.16·A_20ms_ago), on two consecutive hops. Evaluate and latch the first qualifying drop so the second hop compares against the same pre-drop reference (current A must still be below its threshold). Abrupt damping of a well-powered note releases early. A slow natural fade goes to Hold. At low levels a mute and a natural decay are indistinguishable; the finite hold wins.
- Define fresh input support as Q≥.74, valid in-range f and A≥T_keep. Start candidates also require A≥T_on. At reset clear all confirmation counters, set previous amplitudes to zero and allow the first pick immediately. Consecutive-frame counters restart on an ineligible hop. Use the newest frame as the first of a new pair if successive candidates differ by more than 65 cents. Never refresh a hold timer from synthesized or post-Attack audio. Maintain a per-gesture maximum A_pk of A from the event up to launch. Starting dynamics U=clip((20log₁₀(max(A_pk,1e−6))+52)/40,0,1). Capture U, brightness B₀ and polarity. Set scale G=clip(A_pk/.14,.08,1.4) so a quiet DI stays quieter. For supported frames follow a target U_live=.65U+.35·clip((20log₁₀(max(S,1e−6))+52)/40,0,1); held frames freeze U_live. V=.06+.10U_live m/s. Use positive V and apply captured polarity to the emitted signal. For a legato replacement use the polarity captured by the same bucket rule at confirmation. Take pressure ratio R=1.2+1.2·clip(.50·saturation+.25·U_live+.25·B_live,0,1), B_live=.5(B₀+B) on good frames and frozen during Hold. Saturation also controls the existing output-side mid-band softening. These assignments preserve a use for the established dial and make the contact respond to playing dynamics. Initialize V,R immediately at silent launch, then smooth both with 15 ms time constants.
- A player cannot specify continuing bow duration by the amplitude of an already silent pluck. Default to **750 ms from last supported frame** plus a 100 ms release, with earlier release for a confident mute or replacement by the next note. No pedal or UI extension is required. Continuous viable input may keep a note going indefinitely. On active-to-silent transitions the causal analyzer and RMS filter can briefly see input history. An extra hard rule starts Release no later than 800 ms after the last |x|>.0001 FS sample regardless of analyzer state. A silent stream never opens a new voice.

### Transition table

Counters use elapsed samples; continuous gain, speed and delay updates run per sample. Events are ordered reset/fault, new pick, mute, confirmed pitch change, ordinary support, timeout. Only one voice sounds in each lane.

| State | Entry | Output and controller | Exit |
|---|---|---|---|
| Idle | Prepare/reset, completed release or failed acquire | Wet gain zero, wave invalid, direct shaped guitar at unity, maintain analyzer/noise floor. | Opening condition → Acquire. |
| Acquire | New event or soft entrance. If a voice was already sounding, use Release with pending acquisition as below. | Direct stays audible. Collect A_pk, orientation and candidates. For picked starts require end−event ≥ D·(W+K−1)+16D host samples, so the effective centers of all decimated observations postdate the pick. The anti-alias FIR still has a short causal memory around each center. For soft entrance the two already observed qualifying frames may launch directly. Wet stays at zero until accepted. | Two strong adjacent frames → Bowed; use last Hz and M4 initial history. After 120 ms without confirmation → Idle. Require a new event/qualified pair; do not retrigger on a single stale frame. |
| Bowed | Confirmed launch or compatible reacquisition from Hold | Launch under wet gain E=0, ramp to 1. Use linear rise over max(8 ms, Attack ms); Attack automation changes remaining slew at 1/max(8 ms,current smoothed attack). For returning from Hold retain E and rings. Continue physical contact M3. Update pitch via M2 and dynamics above. | Pick → 5 ms Release with pending Acquire, even at the same Hz. Mute → 35 ms Release. Three strong continuous candidates >150 cents from last accepted → 5 ms Release with confirmed pending target. First frame without support → Hold. |
| Hold | Unsupported or an unconfirmed large pitch step | Keep last Hz, V,R,G, current feedback, complete any in-progress ramps. Freeze dynamics. Count from last support. Continue candidate checks on live input. Direct path remains live. A loud unvoiced interruption lasting 60 ms (A≥T_on with Q<.74 or no Hz) shortens hold to Release, so ambiguous strums take over the direct path. | Compatible supported pitch → Bowed with continuous history; new pick/mute/three confirmed large-step frames act as in Bowed. Deadline → 100 ms Release. |
| Release | Mute, timeout, rearticulation or numerical fault | Lift contact immediately and fade E linearly from its actual value to zero over assigned duration. Retain passive waves until gain zero. On fault, immediately invalidate only this lane and execute the N-sample M6 cached fade, counting the fault sample as step 1. A pending event may collect evidence during the fade and cannot extend it. Use the cached product directly in the wet term of A4 for these samples, avoiding a second multiplication by E. Pending event can collect acquisition frames while old wet fades; preserve event timestamp. Keep direct input live. A fresh event during release supersedes the pending event and shortens remaining fade to at most 5 ms. | At zero discard wave and wet-body state for that lane. Launch ready confirmed target at zero gain, else enter Acquire for a pending event or Idle. Never revive a partly released orbit in-place. |

On entering Bowed set last-support time to the launch frame, initialize U_live=U and B_live=B₀, and use G unchanged until a replacement launches. A normal timeout or mute consumes its event, clears pending acquisition, and requires fresh evidence after release. When a pick arrives during an older pending acquisition, replace the pending timestamp, polarity, A_pk and confirmation counters together. For a legato candidate outside 150 cents, freeze the previous pitch, count fresh qualifying candidates at the new pitch, and enter Hold while confirming. Three strong frames with successive intervals ≤65 cents confirm and start a new launch without waiting for a pick. Set its capture levels from these frames. If candidates return near the original note first, cancel the change and resume. A continuous slide whose hop increments stay below the jump threshold normally retains its wave history. A same-note repick depends on an acoustic rise; a repick acoustically indistinguishable from a steady note will continue the stroke.

## A4. Mix and host contract

Let c be smoothed Bow Character, E the state-machine wet gain, w the M5 wet output including its captured G and polarity, d the original Attack-shaped direct sum. Mix y=(1−cE)d+cEw. Full Character replaces the pick progressively once a stable note is available. While waiting for a pitch the listener hears d, including the existing attack suppression. At c=0 the engine can track invisibly so a later automation step sounds continuous. The brief mix overlap is not phase-coherent resynthesis; test level dips on DI and full-wet captures independently. Noise and Movement color only the small body return. Update its deterministic modulation once per host frame, even if all lanes are idle; clear lane-local modal states on completed release. Keep existing 15 ms depth smoothing, direct Attack, and smoothed 0…2 output trim plus .98 linked protector. Normalize neither blocks nor tails to peak. The optional future polyphonic extension would need estimates and association for multiple strings; it is outside the monophonic migration.

**JUCE integration.** Keep Control IDs, units/order/version hints and defaults (attackMs=50, other five=.5, ranges as at baseline), v5 save, v1–v5 readers, host automation and gestures. New sound applies to old values. No wet note is serialized. Active sample values come from the existing once-per-host-block snapshot and Rust smoothing. Identical sample-timestamped controls must yield the same output across internal chunk sizes; different host automation timestamps can legitimately differ. C++ owns JUCE buffers and the handle lifetime; single callback thread has exclusive handle access. UI reads host parameters and atomic meter only. Keep the idle legacy note field and existing WebView. Keep zero fixed transport delay and current bypass ramp. Report a conservative **1.25 s tail** when synthesis is supported, including hold, silence guard, release and margin. Outside that range retain max(.30,1200/fs) seconds for admissible positive rates. A separate future JUCE-only defensive change shall admit finite positive fs≤INT_MAX/.30 only when the binary64 1200/fs is finite. At round-to-nearest the least admissible binary64 fs is 0x1.2c00000000001p−1014 (hex exponent −1014); its immediate predecessor overflows. For positive overflow, nonfinite or overlarge rates the host tail query returns zero. Retain the existing .30 s query sentinel for finite nonpositive rates, which prepare still rejects. This rule is host-specific. Rust C ABI dimensions, the six controls, v5 writer, older readers, fixed latency and fallback rates in the qualification matrix retain their contracts. Add a processor test querying the prepared rate via the host's actual rate setup. No prediction/lookahead or delayed dry line is introduced. ## Evidence still needed for release

The numerical study covers the static control point and seed mechanism. It does not establish lock reliability on recorded pickups, behavior during time-varying delay, immunity to hum, acceptable stereo localization, or bow realism. Thresholds, output conversion, pressure map and direct/wet balance are design constants with named validation gates. Change them only with recorded fixtures and a repeated full-range run. If single-channel chord input appears highly periodic it may capture a common subharmonic. The first release promises a usable direct fallback on rejected material and one modeled voice per lane, not general chord separation.
