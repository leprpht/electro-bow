# Bundled fonts

- Barlow Condensed Medium: https://github.com/google/fonts/tree/main/ofl/barlowcondensed
- Lobster Regular: https://github.com/google/fonts/tree/main/ofl/lobster

Both fonts use the SIL Open Font License; the full licenses are included here.
Vite inlines these files into the production CSS so the JUCE resource provider
can serve the complete interface offline without additional asset routes.
